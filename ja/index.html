macOS 14 Sonoma 以降

Neo LinearPad は

MacBookのトラックパッドの加速度をオフにし、加速のない一定の動きのまま、好みの感度に設定できるアプリです。

macOS 15 Sequoia (2024年9月)以降、LinearMouse等での加速オフでのデバイス使用ができなくなった方も、
本アプリなら現在のOSで安定して使用できます。

Windowsのような素直な操作感を、余るほど広い設定域でご堪能ください。
Magic Trackpadにも対応。

インストール方法（無料版）
  1. ページ上の「ダウンロード」から「30日間無料お試し」を選び、.dmg をダウンロードします。
  2. ブラウザのダウンロード一覧から .dmg を開きます。
  3. Neo LinearPad を「アプリケーション」フォルダへドラッグします。
  4. Neo LinearPad を開きます。初回だけ「インターネットからダウンロードされたアプリです」と確認が出るので、「開く」を押してください。
  5. PC右上に出るアイコンをクリックし、スイッチをオンにします。
有料版 購入後の流れ
  1. ページ上の「ダウンロード」から「すぐに買い切り購入」を選び、メールアドレスとお支払い情報を入力して購入します。ライセンスキーは、入力したメールアドレスにも届きます。
  2. 購入が終わると出る画面で、「Set up Neo LinearPad」を押します。同じボタンは、購入完了のメールにもあります。
  3. 無料版の有無にかかわらず、同じアプリが自動でダウンロードされます。
    無料版を使われたことの無い方は、ダウンロードされたファイルをクリックし、アプリケーションにドラッグして一度アプリを開いてください。詳しくはこちら
  4. ページの「こちらをクリックでライセンスを自動登録」を押します。ブラウザにアプリを開くか確認が出たら、「許可」（Chrome では「Neo LinearPad を開く」）を押します。
  5. アプリに「ライセンスが有効になりました」と出れば完了です。
  6. うまくいかないときは、メニューバーのアイコンを右クリックして「ライセンスキーを入力…」を選び、メールに届いたキーを貼り付けて「有効化」を押します。

詳細

  • スクロールやジェスチャ操作、マウス等の設定には一切影響を及ぼしません。
  • アプリを終了しても感度等、設定データは保持されます。
  • 本アプリはアクセシビリティ等権限設定不要で使えます。
  • アプリ内のスイッチで本機能をオフにすることで、アプリ終了時と同等の効果でログイン項目を維持できます。
  • 動作に支障をきたす他のアプリをチェックする（簡単）

    LinearMouseなど、他のポインタ系アプリが同時に作動して本アプリの動作に支障をきたしている場合、アプリ内機能でそのアプリを特定できます。

    1. 右上メニューバーのアイコンをクリックしアプリのウィンドウを開きます。
    2. 最下部にある「バグ原因となる干渉アプリをチェック」をクリックします。
    3. その状態で不具合の出た動作（ポインタ移動やウィンドウ切り替え等）をもう一度おこなってください。
    4. 干渉したアプリがボタン下に表示されます。（テストは10分で自動終了します。）
    5. 干渉するアプリを終了する等、対策をお取りください。
    6. 「確認できませんでした」と表示される場合は、Macの管理者ではないユーザーで使っている可能性があります。
  • Macを再起動後、自動で起動しない場合
    1. 画面左上のりんごのマーク（Apple メニュー）をクリックし、「システム設定…」を選びます。
    2. 開いたウィンドウの左側の一覧から、「一般」をクリックします。
    3. 「ログイン項目と機能拡張」（または「ログイン項目」）をクリックします。
    4. いちばん上の「ログイン時に開く」の一覧に、Neo LinearPad があるか確認します。すでにある場合は、その右側のスイッチをオンにすれば完了です。
    5. 一覧にない場合は、一覧のすぐ下にある「＋」ボタンをクリックします。
    6. ファイルを選ぶ画面が開くので、左側の「アプリケーション」をクリックし、一覧から「Neo LinearPad」を選んで、右下の「開く」をクリックします。
    7. 「ログイン時に開く」の一覧に Neo LinearPad を加え、スイッチがオンになっていることを確認します。これでMacを再起動後、自動でNeo LinearPadが起動します。
  • Macを2台以上お持ちの方

    個人間では、購入したライセンスキーを複数端末でご使用いただけます。

    1. 別のMacに、Neo LinearPad（無料版）をインストールします。
    2. ライセンス登録済みのMacで、右上メニューバーのアイコンを右クリックし、「別のMacでも使う…」を選びます。
    3. 表示されたライセンスキーをコピーします。
    4. 別のMacで、右上メニューバーのアイコンを右クリックし、「ライセンスキーを入力…」を選びます。
    5. コピーしたキーを貼り付けて、「有効化」をクリックします。

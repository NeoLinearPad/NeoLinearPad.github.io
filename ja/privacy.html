プライバシーポリシー

Neo LinearPad（以下「本アプリ」）と、このウェブサイトでの情報の取り扱いについて説明します。

1. 本アプリが集めない情報

本アプリは、キー入力、画面の内容、使用状況、位置情報などの個人情報を集めたり、送信したりしません。設定（感度など）と無料お試しの開始日は、お使いの Mac の中にだけ保存されます。

干渉アプリのチェック機能は、お使いの Mac のシステムの記録を、その Mac の中でだけ読み取ります。読み取った内容が外部へ送られることはありません。

2. ライセンスの確認で送る情報

ライセンスキーの有効化のときと、その後1日に1回、ライセンスが有効かを確かめるため、次の情報を販売代行の Lemon Squeezy に送ります。

  • ライセンスキー
  • Mac ごとの識別番号（Mac 本体の番号を暗号化して作ったもので、元の番号は分かりません）

コンピュータ名やお名前などは送りません。インターネットにつながっていない場合は、何も送りません。

3. 購入時の情報

購入手続きと決済は Lemon Squeezy が行います。お名前、メールアドレス、支払い情報などは Lemon Squeezy が受け取り、同社のプライバシーポリシーに従って取り扱われます。開発者がカード番号などの支払い情報を見ることはありません。

4. お問い合わせ

メールでいただいたお問い合わせやフィードバックの内容とメールアドレスは、返信と本アプリの改善のためだけに使います。

5. このウェブサイト

このウェブサイトは Cookie を使用していません。サイトは GitHub Pages で公開されており、アクセスの際の技術的な記録（IP アドレスなど）は GitHub が取り扱います。

6. 変更

このポリシーは、必要に応じて変更することがあります。変更後の内容は、このページに掲載した時点から効力を持ちます。

7. お問い合わせ先

support@neolinearpad.com
